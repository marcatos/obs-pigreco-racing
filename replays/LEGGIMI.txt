S.Marcato Replay — solo replay (+ rec)

Usa questa collezione per streamare/commentare un replay.
Per la gara in diretta usa invece "S.Marcato 42" (Live Race / Live Singolo / Live Triplo).

Streaming replay
1. Apri iRacing → Replay → file .rpy della corsa.
2. In OBS: collezione "S.Marcato Replay".
3. Starting Soon → avvia stream → Replay iRacing (o Replay Monitor / Rec Triplo Live).
4. Play in iRacing e commenta in cam (opzionale: vedi sotto).

Scene
- Replay iRacing       Game Capture + badge REPLAY + Cam PIP (opzionale)
- Replay Monitor       monitor centrale + REPLAY + Cam PIP (opzionale)
- Rec Triplo Live      iRacing + bande brand (REPLAY) + cam in fascia
- Rec Singolo Live     centrale + REPLAY + Cam PIP (opzionale)

Cam PIP (opzionale)
- Nelle scene Replay */Rec Singolo Live c’è la source **Cam PIP** (webcam + riquadro con label CAM).
- Occhio in Sources: un click mostra/nasconde cam e riquadro insieme.
- Su Rec Triplo Live la cam è lo slot in basso a destra (label CAM sulle bande).

Registrazione (pulita, senza overlay/cam)
- Rec Singolo          monitor centrale
- Rec Triplo           solo Game Capture iRacing

Per Rec Triplo / Replay iRacing: avvia iRacing (o il replay) prima, così Game Capture
trova "iRacing.com Simulator". Se è nero: proprietà → seleziona la finestra.

Video file (opzionale)
- Se metti qui un file race-replay.mp4 e rigeneri il pack, compare Replay Video.
- Senza quel file OBS non deve chiedere nulla: usa Replay iRacing / Rec.

Telecronaca (classifica / focus / flag)
1. pip install -r adapters/telemetry/requirements.txt
2. Apri il replay in iRacing, poi: Start-Telemetry.bat iracing
   (per test UI senza sim: Start-Telemetry.bat mock)
3. Pannello config → attiva "Overlay broadcast attivo".
4. Nelle scene Replay */Rec * Live: occhio su **Overlay Broadcast Chrome**
   (di default è spento).
Dettagli: docs/TELEMETRY_BROADCAST.md
