# Interstitial background music (OBS)

Original **synthesized** bed loops for **Starting Soon**, **BRB**, **Ending**.

These are generated by `tools/generate_interstitial_music.py` (no third-party
samples). They are meant to avoid Twitch Content ID / mute matches that often
hit Pixabay, SoundHelix, and other library tracks even when “royalty-free”.

| File | Mood |
|------|------|
| `starting-soon.mp3` | Dark carbon pulse / waiting |
| `brb.mp3` | Cooler hold |
| `ending.mp3` | Slightly warmer resolve |

License: original to this repo — free to use for your streams/VODs with this pack.

Regenerate:

```powershell
python tools\generate_interstitial_music.py
```

OBS Media Source uses **looping** + restart on scene activate. Volume: Mixer → `Music …`.

If you prefer silence instead, delete the three MP3s and re-run `generate_pack.py`
(the Music sources are skipped when files are missing).
