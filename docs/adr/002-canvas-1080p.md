# ADR-002: Canvas locked to 1920×1080

## Status

Accepted — 2026-07-31

## Context

Streamer output is 1080p; earlier 1440p canvas caused confusing transforms.

## Decision

Base canvas and overlay artboards are **1920×1080**. Monitor captures scale into that canvas.

## Consequences

- Simpler mental model for teammates.
- 1440p gameplay is scaled down in-canvas (acceptable for Twitch 1080p).
- **Recording** at native 1440p is a separate profile/collection — see ADR-007.
