# S.Marcato 42 Personal Pack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a second OBS scene collection «S.Marcato 42» with carbon/steel typographic overlays, no PiGreco brand, no sponsors, feature parity for countdown/session/BRB/Twitch ending/stinger/config.

**Architecture:** Twin overlay tree at `overlays-marcato/` (own theme + HTML + config) reusing existing runtime scripts from `overlays/` via relative `../overlays/*.js`. Scene collection generated by extending `tools/generate_pack.py` with `--profile marcato`. Config server gains `?profile=marcato` to read/write Marcato JSON.

**Tech Stack:** HTML/CSS overlays, OBS Studio scene JSON, Python 3 (stdlib HTTP + generate_pack), existing overlay JS (`countdown.js`, `session-badge.js`, `brb-timer.js`, `config.runtime.js`).

## Global Constraints

- Keep PiGreco pack behavior and assets unchanged unless a shared tool needs a backward-compatible extension.
- Canvas / output remain **1920×1080**; do not cover center FOV on live scenes.
- Visual: carbon + white + steel/silver only — **no** PiGreco green/blue, Orbitron/Rajdhani, neon glow, sponsor rows.
- Brand lockup: typographic **`S.MARCATO`** + race number **`42`** only (no invented logo mark).
- Ending CTA: Twitch follow `@senormarcato` — **no** Discord QR on Marcato.
- `sponsorsEnabled: false`; do not mount `sponsors.js` on Marcato live chrome.
- Reuse `window.PIGRECO_CONFIG` key name in generated `config.js` so existing scripts keep working (name is historical; do not rename globally in v1).
- Conventional Commits; one commit per task.
- Windows-first; `.bat` files must use **CRLF**.
- Do not hand-edit OBS relative transforms — use `generate_pack.py`.

```javascript
(function initEndingCta() {
  const root = document.querySelector("[data-ending-cta]");
  if (!root) return;
  const cfg = window.PIGRECO_CONFIG || {};
  if (cfg.endingCtaEnabled === false) { root.hidden = true; return; }
  const ctaEl = root.querySelector("[data-ending-cta-text]");
  const followEl = root.querySelector("[data-ending-follow]");
  if (ctaEl) ctaEl.textContent = (cfg.endingCtaText || "Segui su Twitch").trim();
  if (followEl) {
    followEl.textContent = (cfg.endingFollowText || ("Segui " + (cfg.twitchHandle || "") + " su Twitch")).trim();
  }
  // Never show Discord QR in Marcato pack
  const qr = root.querySelector("[data-ending-qr]");
  if (qr) qr.hidden = true;
  root.hidden = false;
})();
```

```python
PROFILES = {
    "pigreco": ROOT / "overlays",
    "marcato": ROOT / "overlays-marcato",

def resolve_overlay_root(profile: str | None = None) -> Path:
```
