# P3-03 Track Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Peripheral Browser Source track map with cars as dots along open/learned/generic path, fed by additive `mapCars` on telemetry ticks.

**Architecture:** Pure `domain_track_map.py` for normalize id, simplify polyline, distPct→point. Bridge/mock emit `trackId` + `mapCars`. Overlay resolves open → learned → generic and draws SVG path + dots. Self-learn writer in bridge (gitignored output).

**Tech Stack:** Python 3, existing telemetry WS, HTML/CSS/JS overlay, pytest.
