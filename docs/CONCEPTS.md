# Concepts

| Term | Meaning |
|------|---------|
| Scene collection | OBS JSON listing scenes/sources (`PiGreco_Racing`) |
| Live chrome | Transparent overlay (`live-chrome.html`) over gameplay |
| Interstitial | Full-screen branded scene (Starting / BRB / Ending) |
| pos_rel | OBS 32 relative transform; `0,0` is canvas **center**, not top-left |
| Sponsor rotator | Corner widget cycling partner logos with gaps |
| Pack | Whole repo folder shared as zip to teammates |
| Workstream | Parallelizable slice of ROADMAP with its own brief |
| ADR | Architecture Decision Record — locked choice |
